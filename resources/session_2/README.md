# Session 2

## Session Overview

- Investigation objective: control movement, speed, turning, and visible status indicators.
- Robotics concept: feedback systems and operator monitoring.
- Expected behaviour: the robot changes speed, performs simple turns, and uses LEDs to show active states.

## Equipment Required

- Maqueen robot
- micro:bit
- battery pack
- USB cable
- computer with a micro:bit editor

## Library Functions Used

- `Maqueen.set_motor()`
- `Maqueen.motor_stop_all()`
- `Maqueen.led_left()`
- `Maqueen.led_right()`

## Student Tasks

- complete the `drive()` helper
- compare speeds `20`, `50`, `80`, and `100`
- build a left and right turn
- use LEDs as simple status indicators

## Evidence Collection

- speed and stability observations
- turn accuracy notes
- LED visibility notes in different lighting
