# Software List

Software and tools required for this unit, with setup guides and references.

## Microsoft Visual Studio Code (VSCode)

- Download: https://code.visualstudio.com/
- Install the Microsoft Remote-SSH Extension: https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh
- SSH Tutorial: https://code.visualstudio.com/docs/remote/ssh-tutorial
- Video guide — using VSCode to remotely connect to the Raspberry Pi board (e.g. `ssh pi@192.168.1.2`): https://www.youtube.com/watch?v=CDjqhAN5RqA

## TigerVNC

- Website: https://tigervnc.org/
- Download from the GitHub release page: https://github.com/TigerVNC/tigervnc/releases
- Raspberry Pi guideline: https://www.raspberrypi.com/documentation/computers/remote-access.html#vnc
