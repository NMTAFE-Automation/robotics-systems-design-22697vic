# Session 1

## Session Overview

- Investigation objective: identify basic robotics system parts and observe how simple code produces visible robot behaviour.
- Robotics concept: inputs, processing, outputs, and environmental effects.
- Expected behaviour: the robot moves forward for a fixed time and then stops so students can observe repeatability.

## Equipment Required

- Maqueen robot
- micro:bit
- battery pack
- clear testing surface

## Library Functions Used

- `Maqueen.set_motor()`
- `Maqueen.motor_stop_all()`

## Student Tasks

- Complete the `forward()` and `stop()` helpers.
- Run the robot for different time values.
- Compare how timing and environment affect travelled distance.

## Evidence Collection

- hardware components identified
- observed robot movement
- notes about battery, surface, and timing effects
